# Student Grade Calculator

A simple C# console application that calculates a student's average grade and determines whether the student passed or failed.

## Features

- Accepts student's name
- Accepts three grades
- Calculates the average
- Determines Pass or Failed status

## Technology Used

- C#
- .NET
- Visual Studio Code

## Sample Output

Enter student name: Juan
Enter Grade 1: 85
Enter Grade 2: 90
Enter Grade 3: 88

===== STUDENT RESULT =====
Name: Juan
Average: 87.67
Status: PASS
